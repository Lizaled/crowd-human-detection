#  CrowdHuman Person Detection

Проект по разработке системы детекции людей в условиях высокой плотности толпы на основе архитектуры YOLOv8. Работа выполнена в рамках учебного курса по компьютерному зрению командой из 3 человек.

##  О проекте

Целью работы является создание надежного детектора, способного идентифицировать людей даже при сильных перекрытиях (окклюзиях) и частичной видимости. В качестве основы использован сложный бенчмарк **CrowdHuman**, содержащий более 15 000 изображений с плотными скоплениями людей.

### Ключевые особенности решения:
- **Адаптация под окклюзии:** Использование аугментаций `Mosaic`, `MixUp` и `CopyPaste` для обучения модели распознавать частично скрытые объекты.
- **Оптимизация разметки:** Приоритетное использование `vbox` (visible box) вместо `fbox` (full body) для фокусировки на видимых частях тела.
- **Полный ML-пайплайн:** Автоматизированные скрипты для скачивания данных, конвертации в формат YOLO, обучения и визуализации результатов.
- **Скорость инференса:** Модель YOLOv8n обеспечивает ~150 FPS на GPU Tesla T4, что позволяет использовать её в системах видеонаблюдения реального времени.
